# SEO

> Public site SEO setup. Implemented in V1, ready for indexing on first deploy.

## Strategy

Long-tail organic, no paid yet. The site targets two intents:

1. **"AI clipping tool"** — competitive but high intent. We don't try to outrank Opus / Klap; we position with "campaign-first" as the differentiator.
2. **"clip YouTube into shorts"** style queries — long tail, easier to rank. Each marketing page targets one cluster.

## Page targets

| URL | Primary keyword cluster |
| --- | --- |
| `/` | "campaign-first AI clipping", "AI shorts from long video" |
| `/features` | "story arcs in AI clipper", "explained virality score" |
| `/pricing` | "AI clipping pricing", "clipping per minute" |
| `/faq` | long-tail support intent — feeds Google "People also ask" via JSON-LD FAQPage |
| `/about` | brand / trust |
| `/changelog` | freshness signal (Google rewards updates) |

## What's in place

### Per-page metadata

Every page exports a `Metadata` object with `title`, `description`, `alternates.canonical`. The root layout (`apps/web/app/layout.tsx`) sets the defaults: `metadataBase`, `template title`, `keywords`, `robots`, `openGraph`, `twitter`, `themeColor`.

### sitemap + robots

- `apps/web/app/sitemap.ts` → emits `/sitemap.xml` listing 8 URLs with priority and changeFrequency.
- `apps/web/app/robots.ts` → emits `/robots.txt` with allow `/`, disallow `/app/`, `/admin/`, `/auth/`, `/api/`, `/login`. Points to the sitemap.

### Open Graph image

Dynamic edge-runtime OG image at `/opengraph-image` (1200×630, PNG). Generated by `apps/web/app/opengraph-image.tsx` using `next/og`. Referenced as the default OG and Twitter card image.

### Structured data (JSON-LD)

Defined in `apps/web/components/marketing/json-ld.tsx`:

- `OrganizationJsonLd` — on the landing.
- `SoftwareApplicationJsonLd` — on the landing.
- `BreadcrumbJsonLd` — on `/about`, `/features`, `/pricing`, `/faq`, `/changelog`.
- `FaqJsonLd` — on `/faq` (15 Q/A items). Feeds the FAQ rich result on Google.

### Site config (single source of truth)

`apps/web/lib/site.ts` exports `SITE` (url, name, descriptions, twitter handle, contact email, founder name, pricing) and `NAV_PRIMARY` for the marketing nav. Everywhere else imports from here. Change once, propagates to nav, footer, metadata, OG image, JSON-LD.

## Env requirement

`NEXT_PUBLIC_SITE_URL` — default `https://clipfactory.app`. Override in `apps/web/.env.local` if deploying to a preview domain.

## To do after first deploy

1. **Google Search Console** — verify ownership (DNS TXT or HTML file), submit `/sitemap.xml`.
2. **Bing Webmaster Tools** — same routine.
3. **Index check** — `site:clipfactory.app` on Google a week after deploy.
4. **Lighthouse** — run on each marketing page, target ≥ 95 on SEO and ≥ 90 on Performance.
5. **Schema validator** — paste `/` HTML into `https://validator.schema.org/` to confirm Organization + SoftwareApplication parse cleanly.
6. **Open Graph debugger** — Facebook Sharing Debugger, Twitter Card Validator, LinkedIn Post Inspector.
