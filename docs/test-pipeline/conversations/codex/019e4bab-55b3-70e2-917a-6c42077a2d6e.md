Pour la partie calcul, ne la mets pas dans le serveur web. Il faut séparer :

1. **Web app**
   Reçoit les vidéos/URLs, affiche le dashboard, gère comptes/paiement.

2. **Queue**
   Stocke les jobs à traiter : `download`, `transcribe`, `analyze`, `render`.

3. **Workers calcul**
   Machines séparées qui prennent les jobs et font le lourd : `yt-dlp`, Whisper, vision, Codex/API, FFmpeg.

4. **Storage**
   Les vidéos sources et clips finis vont dans S3/R2/Supabase Storage, pas sur le disque du serveur web.

Pour toi je ferais en 2 étapes.

**Étape 1, MVP pas cher**
Tu gardes le calcul sur ta machine ou un Mac dédié chez toi. La web app envoie les jobs dans une queue cloud, et ton worker local les récupère. Avantage : presque zéro coût cloud lourd, tu peux tester avec de vrais utilisateurs. Inconvénient : si ta machine est éteinte ou saturée, le SaaS ralentit.

Schéma :

```text
User -> Web app -> DB/Queue -> Worker sur ton Mac -> Storage cloud -> Web app
```

**Étape 2, vrai SaaS**
Tu passes les workers sur des machines cloud avec autoscaling.

```text
User -> API -> Queue -> Worker CPU/GPU -> Storage -> DB -> Dashboard
```

Pour ClipFactory, je découperais les jobs comme ça :

```text
job 1: download video
job 2: extract audio + transcribe
job 3: analyze transcript
job 4: render clips
job 5: upload/store results
```

Le plus lourd, c’est **transcription + rendu FFmpeg**. L’analyse IA coûte moins en machine, mais peut coûter en API. Donc au début : limite forte par utilisateur, par exemple `1 vidéo à la fois`, `max 30 min`, `max 5 clips`, puis tu mesures.

Stack pragmatique :
- API/web : Next.js ou FastAPI
- DB : Postgres/Supabase
- Queue : Redis + RQ/Celery, ou Supabase queue au début
- Workers : Docker Python avec FFmpeg, yt-dlp, Whisper
- Storage : Cloudflare R2 ou S3
- IA SaaS : API normale, pas ton Codex CLI local

Le meilleur premier move : transformer ton pipeline actuel en **worker headless** qui prend un job JSON et écrit les résultats dans un dossier/storage. Après seulement tu branches l’interface SaaS dessus.
